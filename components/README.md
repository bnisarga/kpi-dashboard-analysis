# Components Directory (`components/`)

This directory contains all reactive React components that make up the **Insight Engine** user interface and interactive analytics workspace.

---

## Component Index & Technical Overview

| Component File | Role & Purpose | Key Dependencies / Imports |
| :--- | :--- | :--- |
| **`FileUpload.tsx`** | Handles local CSV and Excel (`.xlsx`/`.xls`) drag-and-drop file ingestion using `PapaParse` and `SheetJS`. Parses files 100% in-browser. | `papaparse`, `xlsx`, `lucide-react`, `DataContext` |
| **`DataCleaningReport.tsx`** | Displays real-time data quality metrics: missing values fixed, whitespace trimmed, Z-score outliers clamped ($|Z| > 3$), dates standardized, and duplicates removed. | `lucide-react`, `DataContext` |
| **`EvaluationMetrics.tsx`** | Interactive empirical model evaluation panel. Features Isolation Forest hyperparameter sliders ($s_{thresh}, N_{trees}, \psi$), live dataset execution timings, synthetic benchmark comparison tables, latency scaling graphs, and Markdown report export. | `lucide-react`, `recharts`, `anomalyDetection`, `benchmark`, `DataContext` |
| **`DataPreview.tsx`** | Dynamic tabular preview of cleaned dataset rows with column sorting, text search filtering, pagination, and numeric formatting. | `lucide-react`, `DataContext` |
| **`CorrelationMatrix.tsx`** | Heatmap matrix rendering Pearson correlation coefficients ($r \in [-1, 1]$) between numerical variables. Includes interactive correlation threshold slider and automated natural language insight callouts. | `correlation.ts`, `lucide-react`, `DataContext` |
| **`KPISuggestions.tsx`** | Interactive recommendation cards generated by heuristic rules (linking categories to metrics, temporal date trends, scatter correlations). Allows one-click pinning to dashboard grid. | `kpiSuggestions.ts`, `lucide-react`, `DataContext` |
| **`FilterBar.tsx`** | Allows users to create dynamic row filters (`equals`, `contains`, `greater`, `less`) applied reactively across all dashboard charts and statistical aggregations. | `lucide-react`, `DataContext` |
| **`AdvancedAnalytics.tsx`** | Displays macro statistical distributions, summary key metrics (sum, mean, variance, standard deviation), and data distribution overviews. | `analytics.ts`, `lucide-react`, `DataContext` |
| **`CalculatedFieldBuilder.tsx`** | User interface for defining custom calculated fields using mathematical expressions (e.g. `[Sales] - [Cost]`). Evaluates row-by-row arithmetic 100% client-side. | `lucide-react`, `DataContext` |
| **`KPIBuilder.tsx`** | Manual KPI builder form allowing users to select target dimensions, numerical metrics, aggregations (`sum`, `average`, `count`, `min`, `max`), and chart types (`bar`, `line`, `pie`, `area`, `scatter`, `radar`). | `lucide-react`, `DataContext` |
| **`DecisionSupportPanel.tsx`** | AI decision support panel providing executive summary insights and scenario analysis powered by Google Gemini AI. | `decisionSupport.ts`, `lucide-react`, `DataContext` |
| **`DashboardGrid.tsx`** | Main dashboard grid rendering all pinned KPI cards using `Recharts`. Includes toggles for Isolation Forest anomaly overlay points and sensitivity controls. | `recharts`, `anomalyDetection`, `lucide-react`, `DataContext` |

## Architecture Standards
- All components use the `"use client"` directive for Client Component execution.
- Reactive state is managed via `useData()` hook exported from `../context/DataContext`.
- Layouts adhere to responsive Tailwind CSS utility classes and modern glassmorphism aesthetic styling.
